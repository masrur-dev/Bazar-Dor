# বাজার দর (Bazar Dor)

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারদর দেখার একটি ওয়েব অ্যাপ্লিকেশন।

## Features
- দৈনিক বাজারদর দেখা
- ক্যাটাগরি অনুযায়ী পণ্য খোঁজা
- বর্তমান ও আগের দামের তুলনা
- পণ্যের বিস্তারিত তথ্য
- Responsive design
- Google Authentication

## Technologies
- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- REST API
- Supabase

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd bazar-dor
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
