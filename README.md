# 🛒 বাজার দর (Bazar Dor)

### বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারদর

**বাজার দর** একটি ওয়েব অ্যাপ্লিকেশন, যার মাধ্যমে বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দৈনিক বাজারদর সহজেই দেখা যায়। চাল, ডাল, তেল, শাকসবজি ও অন্যান্য পণ্যের বর্তমান দাম এবং আগের দামের তুলনা করে বাজারের মূল্য পরিবর্তন সম্পর্কে জানা যায়।

## ✨ Features

- 📊 দৈনিক বাজারদর দেখা
- 🗂️ ক্যাটাগরি অনুযায়ী পণ্য ব্রাউজ করা
- 📈 বর্তমান ও আগের দামের তুলনা
- 🛍️ পণ্যের বিস্তারিত তথ্য দেখা
- 📱 Responsive design — মোবাইল, ট্যাবলেট ও ডেস্কটপে ব্যবহারযোগ্য
- 🔐 Google Authentication

## 🛠️ Technologies Used

- **Next.js** — React-based web framework
- **React** — User interface development
- **JavaScript** — Application logic
- **Tailwind CSS** — Styling
- **DaisyUI** — UI components
- **REST API** — Product and market price data
- **Supabase** — Authentication services

## 🚀 Run Locally

প্রজেক্টটি নিজের কম্পিউটারে চালানোর জন্য:

```bash
# Clone the repository
git clone https://github.com/masrur-dev/Bazar-Dor.git

# Go to the project directory
cd Bazar-Dor

# Install dependencies
npm install

# Start the development server
npm run dev
```

এরপর ব্রাউজারে খোলো:

[http://localhost:3000](http://localhost:3000)
